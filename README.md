# cybersecurity-internship-project

This repository contains the projects I completed during my Cybersecurity Internship.

The projects were performed using authorized vulnerable web applications and local lab environments for educational and security-testing purposes.

## Projects

### 1. Network Reconnaissance & Service Enumeration

Performed reconnaissance and service enumeration on an authorized vulnerable web application.

**Tools used:**

* Nmap
* WhatWeb
* Netcat

**Topics covered:**

* Host discovery
* Port scanning
* Service and version enumeration
* Web technology identification
* HTTP response analysis

---

### 2. Hidden Directory & File Enumeration

Performed directory and file enumeration to identify hidden or unlinked web resources.

**Tools used:**

* Gobuster
* Dirsearch
* Dirb

**Topics covered:**

* Directory enumeration
* HTTP status codes
* Restricted resources
* robots.txt analysis
* Web application structure discovery

---

### 3. Login Traffic Analysis

Captured and analyzed login traffic generated by an authorized vulnerable web application.

**Tools used:**

* Wireshark
* Burp Suite

**Topics covered:**

* HTTP traffic analysis
* POST requests
* Login form data
* Cleartext transmission
* Network security risks

---

### 4. Basic Web Vulnerability Assessment

Performed a basic vulnerability assessment of an authorized vulnerable web application.

**Tools used:**

* Nikto
* Burp Suite

**Topics covered:**

* Security headers
* Cookie security
* Information disclosure
* HTTP methods
* Web server configuration issues

---

### 5. Web Application Penetration Testing – DVWA

Performed a penetration-testing exercise against a locally hosted DVWA environment.

**Tools used:**

* Nmap
* DVWA
* Kali Linux

**Vulnerabilities tested:**

* SQL Injection
* Reflected XSS
* Command Injection
* Local File Inclusion (LFI)

The vulnerabilities were tested in a controlled local environment for educational purposes.
